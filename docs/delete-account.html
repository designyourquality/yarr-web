계정 및 데이터 삭제

YARR(야르) 앱 계정과 그 계정에 연결된 데이터를 지우는 방법이에요. 앱을 다시 설치하지 않아도 이메일로 요청할 수 있어요.

방법 1. 앱에서 바로 삭제

  1. YARR 앱 → 오른쪽 위 설정(톱니바퀴) → 맨 위 계정 줄을 누르세요.
  2. 맨 아래 계정 삭제를 누르고 “삭제”를 입력하세요.
  3. 바로 삭제되고, 앱은 새 익명 계정으로 다시 시작해요.

방법 2. 이메일로 요청

계정 삭제 요청 메일 쓰기

가입한 이메일 주소(또는 앱 설정 화면 맨 아래 계정 ID 복사로 복사한 ID)를 적어 보내 주세요. 본인 확인 뒤 7일 이내에 삭제하고 결과를 메일로 알려 드려요.
